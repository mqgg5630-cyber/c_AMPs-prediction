# 服务对象: script/prediction_attention.py (att.h5) + script/prediction_lstm.py (lstm.h5)
#           即官方 requirement.txt 里的 "For Attention Prediction" 那一组。
#
# 关键说明:
#   * tensorflow 1.14 只有 cp36 / cp37 的 wheel, 所以 python 必须 3.6 (或 3.7)。
#   * 默认装 **CPU 版** tensorflow。原因: RTX A4000 是 Ampere (sm_86),
#     CUDA 10.0 的 cubin 只到 sm_75, TF1.14 的 GPU kernel 在 Ampere 上极大概率报
#     "no kernel image is available for execution on the device"。
#     而 Attention/LSTM 都是 <50AA 肽段的小模型, CPU 上跑百万级肽段也很快。
#   * 想赌一把 GPU: TF_FLAVOR=gpu bash amp_pipeline/install_envs.sh
#     (会改装 tensorflow-gpu==1.14.0 并额外装 cudatoolkit=10.0 + cudnn=7.6)
#   * 每一个版本号都是 "python3.6 + manylinux + PyPI 上确实存在 wheel" 的组合,
#     所以整条安装 **不需要编译 C 扩展, 不需要 gcc**。
# =============================================================================
