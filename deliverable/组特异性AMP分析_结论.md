# 组特异性 AMP 分析结论（v1 精确序列 + v2 证伪 + v3 精确匹配）

日期：2026-09-23；数据：14 组、35,061,523 条三票记录、12,665,622 条唯一三票 AMP（中位长 11 aa）。

## 1. v1：精确序列层面（round 5）

- Cohort2 AD vs NC：共享 199,135（~10%），Jaccard 0.0538；Cohort4：共享 390,206，Jaccard 0.0641。
- Cohort1 五阶段特异 70–76%；core5（五阶段共有）36,851 条。
- AD 特异 vs NC 特异理化特征几乎无差（Cliff's δ < 0.02）；共享/核心序列更短（中位 7–10 vs 15–16 aa）且更富精氨酸。
- 初步判断：极端的"特异性"很可能是组装/菌株噪音，而非疾病信号。详见 `results/group_specific/SUMMARY.md`。

## 2. v2：家族层面尝试被证伪（round 8/9/10）

- 90% 同一性聚类压缩比 1.0x（12,215,326 家族 / 12,665,622 序列），等于没聚类。
- 修好采样 bug 后重测：0.6 阈值下 20 万子样本压缩比仅 1.002x。
- 最近邻搜索：self 搜索仅 40–67% 命中（越短/越 R-rich 漏检越多），跨组 hit 仅 0.1–0.3%。
- 结论：mmseqs 的 k-mer prefilter 对 11 aa 短肽基本全盲，任何依赖预筛的聚类/搜索结论都不可靠；
  且 sORF 名不带 MAG/样本信息，无法做流行率检验。过程见 `results/status/failure_log.md`。

## 3. v3：精确匹配层面，零 mmseqs（round 11）

| 分析 | 结果 |
|---|---|
| A' 跨队列一致性（超几何） | AD-only 跨队列 fold 1.54x（178 万/期望 116 万，z=1145）；NC-only fold 3.10x（155 万/期望 50 万，z=2084）；两个交叉对照**零重叠**（期望 54 万/108 万） |
| D 长度分层（Cohort4 Jaccard） | ≤10 aa 0.1025 → 11–15 aa 0.0476 → 16–25 aa 0.0407 → ≥26 aa 0.0313，单调下降 |
| C 5-mer 富集（chi2+BH） | top1000 **零显著**（最小 BH=0.63） |
| B 深度校正 | 两组记录数比 <2，步长=1 未实际下采样（无效，但反证深度差异不大） |

注意：Cohort1（matched-265）是 Cohort3（full-476）的子集，队列非独立，fold 需打折解读。
178 万条"可重复 AD-only"交集见 `results/group_specific_v3/cross_cohort_AD_intersect.fa`
（75 MB），155 万条 NC 交集见 `cross_cohort_NC_intersect.fa`（66 MB）。

## 4. 综合结论

1. **现象**：AD/NC 三票 AMP 序列库几乎不相交（Jaccard 0.03–0.10），且越长越不共享。
2. **组成**：5-mer 零差异、理化特征零差异——差异只在"采到哪些序列"，不在序列组成偏好。
3. **稳定性**：跨队列划分可重复（fold 1.5–3x，对照零重叠），不是纯随机；但队列非独立。
4. **边界**：在巨大 sORF 空间（1.6 亿唯一）下，上述现象与"采样不饱和 + 个体/组装差异"
   完全相容；**没有样本级 presence 数据，无法区分疾病相关与采样噪音**。
